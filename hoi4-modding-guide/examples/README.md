# 教学示例

完整操作步骤在 [03-first-mod.md](../03-first-mod.md)。

`minimal_mod/` 是教学内容。两份 `.mod.template` 中有明确的版本占位符，需按目标游戏版本填写并移除 `.template` 后缀才能按教程使用。示例没有安装到用户数据目录，也没有在启动器中启用。

中英文 `.yml` 已用 UTF-8 BOM 写入；其他脚本使用 UTF-8 无 BOM。示例不指定图标，以减少对原版图像名称的依赖。首次验证允许显示默认图像，之后再补齐正式资源。
