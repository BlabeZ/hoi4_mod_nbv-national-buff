# BUFF 修正清单与统计模组需求

整理日期：2026-10-25。游戏基准：Operation Postern v1.19.3.0.c01a (5632)。

本目录集中保存当前确认的 **559 项国家全局修正清单**和**统计模组需求建议**。先查词条范围，再按需求书确定界面与开发方案。

| 文档 | 内容 |
|---|---|
| [01 最终 BUFF 修正清单](01-buff-catalog.md) | 六类全部559项，包含高低优先级、三四列分区、名称、技术键、A/B来源等级、作用、条件及依据 |
| [02 统计模组需求建议](02-mod-requirements.md) | 已确认统计与交互要求、独立窗口建议、页面记忆、原版配色、tag刷新、性能、兼容和验收标准 |
| [展示名单 JSON](data/buff-display-whitelist.json) | 供后续生成模组配置使用的同一份数据，包含候选读取表达式及验证状态 |
| [清单核验记录](data/catalog-verification.json) | 559 项唯一性、无名排除、六类计数、来源链接及输入文件哈希 |
| [交付文件核验](data/delivery-verification.json) | 本目录入口、需求书链接和两份文档的对应检查 |

政治 94 项、工业 109 项、陆军 166 项、海军 92 项、空军 51 项、情报 47 项。其中 A 档 521 项有可信国策／国家精神来源，B 档 38 项为其他已选候选。A/B 不表示重要程度或运行验证成功。

统计窗口包含政治、工业、陆军、海军、空军、情报六个页面，通过窗口顶端依次排列的页面按钮切换；当前按钮高亮，顶部按钮不随内容滚动。

已确认：**领袖、法案和顾问授予国家的修正也统计；只读当前玩家国家，切tag刷新；高优先级在前方区域按三列排列，低优先级在后方区域按四列排列；首次政治页，关闭记录分类页并在重开时恢复；红绿配色沿用原版。** 当前依据已有重要度，P0/P1共198项归高优先级，P2/P3共361项归低优先级。

后续已按用户“按照要求进行 mod 制作”的指示实现 [国家 BUFF 统计 UI 本地测试版](../../hoi4-national-buff/README.md)，包含右侧独立入口、可拖动窗口、零值筛选和手动刷新。最新实现与运行验证状态以模组的 [测试报告](../../hoi4-national-buff/TEST-REPORT.md) 为准。

本研究目录中的 `runtime_read_validated` 是制作前的研究快照；实现阶段的逐项取数测试结果保存在模组 `tools/data/engine-validation.json` 和 `metric-index.json`。格式、读数和视觉交互分开验收，不因为读数测试通过就推定所有颜色或交互已通过。

原始全量数据及 C 档排除原因保留在 [全局筛选审计](../vanilla-modifier-catalog/global-buff-review/README.md)，不混入这份最终展示清单。可使用 [离线检索页](../vanilla-modifier-catalog/global-buff-review/catalog.html)搜索已选项和排除记录；该 HTML 页不是游戏内模组界面。

## 维护方式

调整展示范围时，先更新 [用户覆盖规则](../tools/global_buff_user_overrides.json)并运行全局筛选生成器；随后运行 [交付清单生成器](../tools/build_buff_delivery_catalog.py)，更新本目录清单与 JSON。需求书手工维护，并在范围变化后同步修订数量、边界与验收条件。

两个生成器仅整理本地文档与数据。源头与交付文件的 SHA-256 记录在核验文件中，可用于判断游戏更新或名单变更后是否需要重新审查。
