# 民族精神来源遗漏核查

核查版本：本机 HOI4 1.19.3；现有 559 个修正键，当前 GUI 519 个词条。

## 根因

`tools/data/source-bindings.json` 原有 3 个整文件解析失败。现行严格解析器重新生成仍然失败，排除“只要重建旧数据即可”的解释。

- `common/ideas/SOV.txt`
- `common/ideas/persia.txt`
- `common/ideas/switzerland.txt`

三文件均有 `ideas = {` 外包装，但文件结束缺少该包装的闭合花括号。游戏可以加载，工具严格解析拒绝整个文件，因此其中全部民族精神未进入来源表。这不同于动态民族精神问题。

已添加限定修复：仅匹配已核对的原版文件路径及 SHA256 时，在内存中补上 EOF 外层闭合，依然使用原有严格解析器；生成报告记录恢复行为，不修改原版文件。未知文件、改动过的内容和其他语法错误继续拒绝解析。
